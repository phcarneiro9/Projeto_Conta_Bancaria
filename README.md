# 💰 Projeto Conta Bancária

Aplicação de console desenvolvida em **Java** para praticar Programação Orientada a Objetos (POO) por meio de um sistema de gerenciamento de contas bancárias.

## 🚀 Funcionalidades

- Criar contas
- Listar contas
- Buscar conta por número ou titular
- Atualizar conta
- Excluir conta
- Realizar depósitos
- Realizar saques
- Realizar transferências
- Suporte a Conta Corrente e Conta Poupança

## 🧠 Conceitos de POO

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Classes abstratas
- Interfaces

## 🛠️ Tecnologias

- Java
- JDK 21+
- Eclipse / Spring Tool Suite
- Git e GitHub

## ▶️ Como executar

```bash
git clone https://github.com/phcarneiro9/Projeto_Conta_Bancaria.git
cd Projeto_Conta_Bancaria
```

Abra o projeto no Eclipse/STS e execute a classe principal da aplicação.

## 🎯 Objetivo

Projeto desenvolvido para consolidar fundamentos de **Java e Programação Orientada a Objetos** em um cenário prático.
